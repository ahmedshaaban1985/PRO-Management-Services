PRO Management Services - نسخة الديسكتوب
=========================================
1) فك الضغط (كليك يمين > Extract All).
2) دبل كليك على install.bat  (رسالة زرقاء؟ More info ثم Run anyway).
3) محتاج إنترنت أول مرة، وبياخد 3-5 دقايق، وفي الآخر هيكتب DONE والبرنامج يفتح.

البرنامج بيشتغل بـ Python الرسمي من python.org، فحماية ويندوز (Smart App Control) بتسمح بيه.
البيانات: C:\ProgramData\PROManagement\data
